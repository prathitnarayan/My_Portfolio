# Prathit Narayan — Portfolio refresh

A responsive, premium-minimal personal portfolio built with plain HTML, CSS, and JavaScript. The positioning balances backend engineering, AI/ML, DevOps, and performance engineering.

## Files
- `index.html` — page structure, SEO metadata, projects, skills, and experience
- `style.css` — visual system, responsive layouts, and CSS-based project illustrations
- `script.js` — accessible mobile navigation and dynamic footer year

## Run locally
No build step or package installation is required.

```bash
git clone https://github.com/prathitnarayan/My_Portfolio.git
cd My_Portfolio
python3 -m http.server 8000
```

Open http://localhost:8000.

## Review before publishing
1. Replace the LinkedIn placeholder URL in `index.html` with your actual profile URL.
2. Add a resume PDF and link it if you want a downloadable CV.
3. Add repository/demo links for projects only when the links are public and ready to share.
4. Verify project descriptions and status labels against the latest implementation. PAM IdentityFort is described as professional experience; Adaptive Goal Planner is explicitly in progress; equipment price prediction is labeled as an ML exploration.
5. Confirm the configured GitHub Pages publishing branch/folder before replacing files.
